# Payment-method assets

Every asset in this directory is self-contained: no SVG loads an external image, font, stylesheet, or other resource. The PayPal, Bitcoin, and WebMoney marks use the corresponding [Simple Icons](https://simpleicons.org/) paths (CC0). The MoneyGram, Western Union, and Whish Money assets are compact local vector treatments based on their published brand marks. The card asset is a generic payment-card treatment, intentionally not a claim of support for a particular card network.
